# Day 3 上午｜文本分析工作規則

- 只使用 `data/thesis_abstracts_110_114.jsonl` 與 `data/source_manifest.json` 的講師提供資料；不可修改它們、不可下載全文或新增網路來源。
- 分析單位是一篇摘要。原文證據、AI 初步編碼與人工確認必須分開記錄。
- 只可使用 `PROMPTS.md` 指定的編碼值；資訊不足時填 `無法判定`，不可根據題名之外的猜測補足。
- 比較兩校時同時呈現篇數與比例，並檢查碩士與博士的分層結果；不可把差異解讀為品質高低或因果關係。
- 可在 `analysis/` 建立衍生檔；每個結論至少要保留 `corpus_id`、`source_url` 與摘要原文證據。
- 預設使用繁體中文（臺灣），完成後回報檔案位置、筆數、缺漏與仍需人工確認處。
