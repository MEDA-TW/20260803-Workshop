# 維護歷程文件

`plans/` 與 `specs/` 保存 Day 3 教材演進時的設計與執行紀錄，部分內容反映當時的資料夾結構，並非目前的學生操作說明。

目前的正確入口與位置如下：

- 上午學生開啟 `course/day-03/text-analysis-demo/`，依其 `README.md` 與 `PROMPTS.md` 完成摘要探索、主分類確認與 Word 報告。
- 下午學生開啟 `course/day-03/rag-demo/`，依其 `README.md` 與 `PROMPTS.md` 完成校務文件 RAG。
- 健康檢查資料位於 `course/day-03/instructor/maintainer/health-check/`。
- 維護測試位於 `course/day-03/instructor/maintainer/tests/`；指令見 `../README.md`。
- `rag-demo/sample-data/` 與 `rag-demo/tests/` 已不再是目前結構。

修改教材時，請以 Day 3 的 `README.md`、`text-analysis-demo/README.md`、`text-analysis-demo/PROMPTS.md`、`rag-demo/README.md`、`rag-demo/AGENTS.md` 和 `instructor/maintainer/README.md` 為準；不要依歷史 plan/spec 推斷現況。`plans/` 與 `specs/` 中的舊版校務文本設計保留作為歷史紀錄，不代表上午目前定位。
