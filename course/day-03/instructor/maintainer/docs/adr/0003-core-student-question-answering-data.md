# 以修課、英文門檻與表單作為學生助手的最低資料目標

Day 3 的學生助手以能回答實際校務問題為目標，而不只證明 RAG 能運作。每位學生至少取得碩士班修課與畢業學分規定、英文畢業門檻及其適用年度，以及一份相關流程或表單；允許的官方主機為 `tve.yuntech.edu.tw`、`lc.yuntech.edu.tw` 與 `aax.yuntech.edu.tw`。這取代只以文件數量作為可用資料的判斷，讓學生能檢驗回答是否真正有意義。

校務行事曆與公告可作為延伸資料納入，讓助手回答申請、繳交或活動日期；這類回答必須呈現適用學年度或公告日期，不得由舊資料推測最新日期。

學生的固定自我測試包含四類：修課與畢業學分、英文門檻與年度、流程或表單、校務日期。每個答案必須附來源；英文與日期題另須呈現適用年度或公告日期。
