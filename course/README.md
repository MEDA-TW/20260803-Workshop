## 教材檔案慣例

每天的資料夾會用下列慣例組織內容：

```
day-XX/
├── README.md           ← 當天總覽（時程、主題、產出、繳交方式）
├── prompts/            ← 給 AI 的提示詞範本
├── prd/                ← 產品的 PRD（Product Requirements Document）
├── sdd/                ← 技術設計文件（System / Software Design Doc）
└── exercises/          ← 隨堂練習與作業
```
