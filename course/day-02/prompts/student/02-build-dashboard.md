# 02｜建立互動式生源趨勢儀表板

## 直接貼給 Codex

```text
我要使用 data/processed/moe_high_school_departments_standardized.csv，建立「高中職生源趨勢儀表板」。

開始寫程式前，請先檢查標準化資料及 docs/cleaning-report.md，並用簡短清單說明你準備採用的技術、篩選邏輯、學生數口徑與預計產出的檔案。儀表板程式全部放在 dashboard/。

儀表板必須支援由大到小探索：
- 縣市：全部或單一標準化縣市
- 學校：全部或單一學校；選項同時顯示學校代碼與名稱
- 群別：全部或單一群別
- 科系：使用「科系分析主題」做整體趨勢，並可進一步選擇「科系名稱_標準化」查看精確科系
- 日夜別：全部、日間部或夜間部
- 等級名稱：全部或單一類型

所有篩選器必須連動，只顯示在目前條件下確實存在的選項，並提供「重設篩選」。預設畫面顯示全國、全部學校、全部群別、全部科系及全部日夜別。

畫面至少包含：
1. 目前篩選條件摘要。
2. 最新學年度學生數、首末年變化率、最高點及符合條件資料列數。
3. 103–114 學年度學生數折線圖；缺少的年份顯示為缺口，不自動補值。
4. 目前條件下各縣市、學校、群別或科系的比較表，讓使用者可以從整體繼續往下探索。
5. 資料來源、學生數計算口徑及名稱標準化提醒。
6. 下載目前篩選結果 CSV 的功能。

請特別避免重複加總：先依目前篩選條件篩選原始粒度資料，再按學年度加總「總學生數」。科系改名應透過對照欄位呈現，不要在前端用模糊文字比對臨時合併。

完成後啟動本機預覽並檢查瀏覽器主控台沒有錯誤，再更新 docs/progress.md，將 02 標記完成，下一步寫成 03「驗證與發表」。告訴我如何開啟儀表板及目前產生了哪些檔案。
```

完成後應有：可在本機操作、連動篩選並下載結果的生源趨勢儀表板。
