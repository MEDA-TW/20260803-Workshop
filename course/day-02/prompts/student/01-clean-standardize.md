# 01｜清理與標準化生源資料

## 直接貼給 Codex

```text
我要把教育部高中職科別資料整理成可供儀表板使用的標準化資料。

請讀取 data/raw/moe_high_school_departments_103_114.csv。原始檔只能讀取，不可修改、改名或覆寫；所有新檔一律放在 data/processed/ 或 docs/。

第一階段先做資料健檢並向我報告：
1. 資料列數、欄位數、103–114 各學年度筆數。
2. 必要欄位是否存在：學年度、縣市代碼、縣市名稱、學校代碼、學校名稱、群別代碼、群別名稱、科系代碼、科系名稱、日夜別，以及一至四年級男女學生數。
3. 缺值、重複列、文字前後空白、疑似編碼問題。
4. 同一代碼對應多個名稱的情況，特別檢查縣市、學校與科系。

第二階段建立可追溯的標準化資料：
- 完整保留原始欄位，不直接改寫歷史值。
- 新增「縣市名稱_標準化」。處理行政區誤植、六都升格及縣市合併問題；每條規則要記錄適用學年度與理由。
- 學校以「學校代碼」作為主要識別，另保留各年度原始學校名稱。
- 新增「科系名稱_標準化」與「科系分析主題」。同校、同科系代碼若只是名稱或寫法改變，可以統一名稱；不同代碼即使名稱相近，也不可自行合併，必須列出候選讓我確認。
- 總學生數＝一至四年級男、女學生數共 8 欄加總；空值依資料情況處理並留下紀錄。不要加入延修生或上學年畢業生。
- 保留日夜別、等級名稱及群別名稱，讓儀表板可以篩選。

請產出：
1. data/processed/moe_high_school_departments_standardized.csv
2. data/processed/county_mapping.csv
3. data/processed/department_mapping.csv
4. docs/cleaning-report.md

最後進行驗證：比較清理前後各學年度的總學生數與資料列數。名稱標準化不得無故改變人數總和；若有差異，先停止並說明原因，不要繼續製作儀表板。

確認無誤後更新 docs/progress.md，將 01 標記完成，下一步寫成 02「建立互動式儀表板」。
```

完成後應有：標準化資料、兩份名稱對照表與清理報告。
