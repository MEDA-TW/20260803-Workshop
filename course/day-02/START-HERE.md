# START HERE｜高中職生源趨勢儀表板

今天早上的任務，是使用教育部政府開放資料，做出一個能從全國一路篩選到單一學校、單一科系的互動式生源儀表板。

第一次開始，依序使用以下四份提示詞：

| 階段 | 任務 | 提示詞 |
| --- | --- | --- |
| 00 | 建立專案、取得資料、完成資料護照 | [開始專案](prompts/student/00-start-dashboard-project.md) |
| 01 | 檢查資料品質並建立標準化資料 | [清理與標準化](prompts/student/01-clean-standardize.md) |
| 02 | 建立可自由篩選的互動式儀表板 | [建立儀表板](prompts/student/02-build-dashboard.md) |
| 03 | 核對數字、修正問題並準備展示 | [驗證與發表](prompts/student/03-validate-present.md) |

## 做到一半想繼續

把下面這段貼給 Codex：

```text
我想繼續 Day 2 的高中職生源趨勢儀表板。

請先查看 student-work/，若有多個資料夾，列出學號末三碼讓我選擇。選定後讀取 docs/progress.md、docs/data-passport.md、docs/cleaning-report.md，以及目前已有的資料與程式。

請告訴我：已完成哪個階段、目前缺少什麼、下一個最小步驟，以及接下來該使用哪一份 student prompt。先不要重做已完成的檔案，也不要覆寫 data/raw/ 的原始資料。
```

## 最終成果

- 一份保留原始欄位、另加標準化欄位的乾淨資料。
- 一份可以依縣市、學校、群別、科系及日夜別篩選的互動式儀表板。
- 一份清理紀錄與數字核對紀錄，讓分析結果可以回到原始資料查證。

學號末三碼只用來區分個人專案資料夾，不顯示在儀表板標題，也不蒐集完整學號或姓名。
