# Day 1 講師與 TA 指南

## 教學定位

對象是沒有程式背景的師培生、研究生與通識中心教師。成效不是「學會寫程式」，而是：

1. 經歷至少一次「原來可以這樣」的頓悟。
2. 能說出 Agent 三大要素與提示詞四要素。
3. 帶走一個可分享的 Vercel 網址與一套可重複的方法。

## 全日原則

- 學員只使用 Codex Desktop、GitHub Desktop 與瀏覽器。
- 每段重複「描述、產出、驗收、存檔」。
- 上午只 commit；下午部署前才 push。
- 個人名片只由講師 Demo。
- 卡住超過五分鐘，TA 主動介入。

## 五個 Aha 節點

1. 09:05：30 秒名片 Demo。
2. 上午 2.4：學員看到自己描述的儀表板骨架。
3. 上午 2.5：用一句話還原上一版。
4. 下午 3.3：Codex 沿用專案規則與預裝元件。
5. 下午 5.2：用手機打開自己的公開網址。

### 1.7｜五大 Agent 系統：不是誰最強，而是哪種工作適合誰（8 分鐘）

這一段放在「Agent 三大要素」之後、「提示詞四要素」之前。學員已經知道 Agent 都有 LLM、Tools／Skills、Memory，現在才適合看見：同樣三個零件，會因介面、運行環境與任務不同，組成完全不同的產品。

教學目標不是記住五套產品功能，而是會用四個問題選工具：

1. 我要完成的是程式、一般知識工作、個人助理，還是多 Agent 管理？
2. 我要在終端機、桌面／Web，還是通訊軟體裡操作？
3. 資料可以放雲端，還是必須自己控制主機？
4. 任務是做完一次，還是要排程並長期在背景執行？

#### 五套系統的一句話地圖

| 系統 | 課堂定位 | 適合的工作 | 初學者要記住 |
| --- | --- | --- | --- |
| Codex | 程式開發與多步驟交付 Agent | 建網站、改檔案、執行與驗證程式 | 今天選它，因為桌面介面與專案資料夾最適合第一次實作 |
| Claude Code／Cowork | 程式開發核心延伸到桌面知識工作 | 深度 coding、終端機協作、桌面多步驟工作 | 與 Codex 同類但操作環境與產品生態不同 |
| OpenClaw | 開源、自託管的個人執行助理 | 通訊軟體入口、常駐服務、資料自主 | 自由度高，但要自己安裝、維護與管理權限 |
| Hermes Agent | 可高度客製的個人執行助理 | 系統操作、排程、研究工作流、Telegram 整合 | 適合長期個人化流程，不是今天的學員實作工具 |
| LobeHub | 多 Agent 管理平台 | 招募、排程與管理多個 Agent | Agent 多不等於比較好；只有工作真的能分工時才需要 |

#### 8 分鐘講述節奏

1. **第 1 分鐘：先畫分類線。** Coding／知識工作、個人助理、多 Agent 管理不是同一種需求。
2. **第 2–5 分鐘：五套系統各一句。** 只講上表，不展開技能數、star 數、模型價格與功能清單。
3. **第 6–7 分鐘：用今天的任務做選擇。** 我們要在桌面介面改一個 React 專案、立即預覽，所以選 Codex；若目標是 Telegram 常駐助理，才會考慮 Hermes 或 OpenClaw。
4. **第 8 分鐘：讓學員回答。** 「如果我要每天早上自動整理行事曆，會選今天的 coding 工具，還是長期執行助理？」答案不是背品牌，而是先辨認任務。

#### 必講的三個邊界

- 不要問「哪一套最強」；先問任務、介面、資料位置與維護成本。
- 多 Agent 不是能力升級，而是協作與管理成本的交換。
- 開源、自託管不等於自動安全；權限、更新、備份與外部 API 仍要由人管理。

GitHub Copilot 與 Cursor 可以在最後用一句話帶過：它們偏向程式編輯器中的開發協助，這張比較表聚焦能規劃並執行多步驟任務的 Agent 系統，因此不放在同一層比較。

> 今天不是要你安裝五套工具，而是讓你知道：同樣叫 Agent，工作型態可能完全不同。

產品名稱、介面、授權、價格、技能數與多 Agent 功能都會快速變動。課堂投影片只保留定位與選擇邏輯；精確功能必須在課前重新核實。

講述定錨：

> 你可以把手放開，但不能把眼睛閉上。

> 模型決定能力上限；上下文和 Harness 決定上限能否穩定落地。

## TA 排錯手冊

### 介入原則

- 不等學員舉手，Phase 4 主動逐排查看。
- 同一錯誤不讓學員停超過五分鐘。
- 先讓畫面恢復可動，再解釋原因。
- 課堂不展開 Git 概念；必要時 TA 代做還原。

| 症狀 | TA 動作 |
| --- | --- |
| 沒有可用訂閱 | 安排鄰座併機，登記課後追蹤 |
| Codex 登入失敗 | 確認資格，再重新登入或重啟 |
| 沒有語音按鈕 | 繼續打字，不阻塞課程 |
| Open Folder 沒檔案 | 確認 clone 與資料夾 |
| Use this template 失敗 | 使用 ZIP＋Add local repository |
| 預覽空白 | 把完整錯誤貼回 Codex |
| Codex 改錯檔 | 指定正確路徑，要求還原錯誤檔 |
| Codex 想安裝套件 | 回覆「元件已存在，請直接沿用」 |
| 圖表超出卡片 | 檢查固定高度與 ResponsiveContainer |
| Vercel 是舊畫面 | 確認已 Push origin |
| Vercel build 失敗 | 完整 log 貼回 Codex |

標準救援：

> 剛剛的修改讓畫面變差了。請只還原本輪變更，保留前面已完成並 commit 的功能。

> 以下是完整錯誤訊息。請用一句話說明根因，再做最小修正；不要安裝套件或改技術棧。
