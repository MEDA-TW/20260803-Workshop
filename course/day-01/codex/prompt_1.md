# 初始化提示詞

> 把以下內容複製，貼到 Codex 對話框

幫我建立一個學生學習表現的數據儀表板。

## 資料來源
使用專案目錄裡的 rawdata_1.csv。這個 CSV 的欄位是：學生ID、班級、科目、期中成績、期末成績、平時成績、出席率(%)、作業完成率(%)。

## 技術要求
- 前端框架用 React + TypeScript
- UI 元件庫使用 shadcn/ui
- 圖表使用 Recharts
- 樣式用 Tailwind CSS
- 讀取 CSV 資料，不需要後端

## 儀表板內容
請包含以下區塊：

1. 頂部四個統計卡片：
   - 學生總人數
   - 全校平均成績（所有科目、所有學生的平均）
   - 平均出席率
   - 平均作業完成率

2. 各班平均成績比較長條圖（五個班的平均分數對比）

3. 出席率與成績的散佈圖（X 軸出席率、Y 軸平均成績，每個點代表一位學生）

4. 各科目的平均成績長條圖（國、英、數、自、社五科對比）

## 外觀
- 淺色主題，背景白色
- 配色簡潔專業，主色使用藍色系
- 每個區塊用卡片包起來，卡片有圓角和陰影
- 頂部有標題列：左邊「學生學習表現儀表板」，右邊顯示當天日期
