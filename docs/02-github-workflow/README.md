# GitHub 工作流程

> 瞭解實驗室的 Git 分支管理策略與 Pull Request 流程，確保所有人的變更都能安全地合併到主分支。

---

## 為什麼需要這份流程？

在多人協作的專案中，如果每個人都直接修改 main branch，很容易產生衝突或覆蓋別人的變更。透過分支管理和 PR 流程，可以確保：

- 每個變更都經過檢查，才會合併到主分支
- 任何人都可以安心開發，不用擔心影響到其他人的工作
- 變更歷史清楚可追溯，出問題時容易排查
