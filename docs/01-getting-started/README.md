# 環境建置與工具

> 開始之前，需要先把開發環境準備好。這個章節會一步步引導你完成所有必要的安裝。

---

## 安裝順序建議

建議按照以下順序完成安裝：

1. **環境安裝指南** — 安裝 Git、Node.js 等基礎工具（作業系統對應的步驟）
2. **GitHub Desktop** — 安裝圖形化 Git 工具，降低指令操作的門檻
3. **AI 終端機工具** — 安裝 Claude Code 或 Codex CLI，串接 API 或本地端模型

每個檔案都包含驗證步驟，安裝完成後請確認步驟正確執行，再往下一個檔案移動。

---

## 你會需要

- 一台電腦（macOS 或 Windows）
- 穩定的網路連線
- 大約 30 分鐘的時間
- 實驗室 GitHub 組織的帳號（聯繫 Owner 取得邀請）
