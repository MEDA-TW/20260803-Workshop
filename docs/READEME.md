# 指導手冊

## 這是什麼？

這是一份給此次工作坊學員的操作手冊，涵蓋從環境建置到 GitHub 協作的完整流程，可以在這裡找到需要的資訊。

手冊採用 Markdown 檔案管理，方便版本控制與即時更新。每個章節獨立成檔，遇到問題時可以直接搜尋對應的檔案。
