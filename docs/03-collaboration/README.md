# 協作與貢獻

> 這份手冊是活的文件，會隨著實驗室的發展持續更新。每個人都可以參與改善。

---

## 為什麼要一起維護？

手冊的內容會隨著工具更新、流程調整而不斷變化。如果只有一個人負責更新，很容易跟不上實際狀況。讓大家一起參與維護，才能確保手冊內容永遠是最新的。

因為你是組織成員，可以直接在組織的 Repo 中建立分支進行修改，不需要 Fork。整個流程和你在其他專案中開發功能一樣：建立分支、修改、推送、發 PR。
